---
name: Public farmer onboarding boundaries
description: Product decision separating public free-trial farmers from legacy beta workspaces.
---

New public farmers receive a private empty workspace without an invite code. Existing beta farmers retain invitation-based access and their existing animal data; do not implicitly migrate or attach a legacy herd during public registration.

**Why:** The creator requested controlled public free-trial onboarding without rebuilding BREEDLOG, changing production data, or disabling existing accounts.

**How to apply:** Preserve these entry paths when extending authentication or trial onboarding. Creator credit is STITCH WORX.
